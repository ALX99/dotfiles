# Multi-phase plan

1. Establish whether the request is plan-only or authorizes implementation. Inspect contracts, constraints, dependencies, and existing facilities.
2. Resolve the riskiest unknowns first through investigation or disposable prototypes. For replacement proposals, compare equivalent investment in incremental improvement, including migration, coexistence, compatibility, and maintenance.
3. Prefer thin end-to-end phases over completing layers in isolation. Give each phase an outcome, dependencies, risks, and concrete verification. Define approval gates, rollback concerns, and compatibility-transition completion and removal conditions.
4. Present order, tradeoffs, evidence, and unresolved decisions. Write a plan file only when useful within scope; execute only when authorized.
