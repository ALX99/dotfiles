# Prototype

1. Name the decision or uncertainty and the evidence that would distinguish options.
2. Build the smallest disposable experiment in scratch space. Compare alternatives only when they inform the decision; keep throwaway code separate from production.
3. Drive the relevant surface or run the experiment; collect outputs, screenshots, or measurements.
4. Report evidence, tradeoffs, recommendation, and scratch path. Passing the experiment answers only the tested question, not production readiness. For authorized production work, use `feature.md` to build a production-quality slice.
