# Autonomous run

1. Define a checkable completion condition, authorized scope, verification, and stop conditions. Select the task-specific playbook for the actual work.
2. Work in small verified increments; track meaningful progress and decisions. Use a scheduler or watcher only when supported and needed; do not promise background work the harness cannot sustain.
3. Resolve reversible uncertainty from evidence and continue independent work. Autonomy does not expand authorization.
4. Change tactics when blocked and follow shared stopping rules. Finish only when completion is verified; otherwise report evidence, remaining gaps, and what is needed.
