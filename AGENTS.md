# Repository Guide

## Layout and sources of truth

- This is a Stow repo: `home/` installs to `~`, including `home/.local/` and `home/.config/`. `.stowrc` disables folding; keep tracked symlinks intact, especially the Claude/Codex instruction links to the shared `home/.agents/AGENTS.md` (installed as `~/.agents/AGENTS.md`).
- `home/.local/bin/` owns user executables; `home/` owns shell and agent configuration; `home/.config/` owns application configuration; `misc/` owns keyboard layouts and generated assets. Start shell work at `home/.bash_profile`, `home/.bashrc`, and `home/.bashrc.d/`.
- Herdr plugins share CLI/workspace helpers in `home/.config/herdr/plugins/_shared/herdrlib.py`; plugin-specific Git and install policy stays with each plugin.
- `home/.agents/AGENTS.md` is the shared general instruction source for Claude, Codex, and the Cursor user rule generated by `mise run install`; `home/.agents/skills/` contains harness-independent skills. Pi user settings are Stowed from `home/.pi/agent/settings.json`; extensions and other Pi resources remain owned and installed by the separate pi-lot repository.
- Colemak-DH mappings are coordinated across Nvim, Sail, Ghostty, and readline.
- Interactive macOS Bash maps GNU utility names to private aliases instead of adding GNU directories to `PATH`; keep GNU-option aliases in `home/.aliasrc` consistent with those aliases.

## Commands

- `mise.toml` and `.mise/tasks/` define tools, setup, and checks. CI runs `mise run check`; `mise run fmt` formats the repo.
- `mise run shell:check` runs ShellCheck and shfmt on repository shell scripts.

## Host changes

- `mise run install` changes `$HOME`: it restows `home/`, synchronizes skill links (including stale repo-managed links), and may enable the user `ssh-agent`. Do not run it for routine code verification.

Keep this file limited to verified ownership, source-of-truth, and workflow facts; update it when those change.
